图像生成与编辑

Qwen-Image-2.1 可以把提示词变成图像，也可以把提示词加一张或多张参考图变成编辑后的图像。本页包含下载、运行示例、默认值，以及决定出图耗时的设置。

💡

这些命令遵循与文本模型示例相同的约定：Hugging Face CLI、从仓库根目录源码构建，并把 --backend 换成与你硬件匹配的值。参见按家族下载与运行。

Qwen-Image-2.1（提示词 → 图像，提示词 + 图像 → 编辑后的图像）

最短路径是现成的 config/qwen-image-2.1.json。它固定仓库修订版本与 SHA-256 校验，缺什么下什么（共四个文件，约 10.29 GiB），存放到 $TENSORSHARP_MODELS/qwen-image-2.1/；未设置 TENSORSHARP_MODELS 时为仓库内的 models/qwen-image-2.1/。该配置选择 ggml_metal；在已构建 CUDA 后端的 NVIDIA 机器上追加 --backend ggml_cuda，原生 CPU 后端为 ggml_cpu。

dotnet build TensorSharp.Cli/TensorSharp.Cli.csproj -c Release
dotnet build TensorSharp.Server.Host/TensorSharp.Server.Host.csproj -c Release

# 文生图
dotnet run --project TensorSharp.Cli -c Release --no-build -- \
  --config config/qwen-image-2.1.json \
  --prompt 'A small orange cat beside a blue ceramic vase, soft daylight, detailed photograph' \
  --width 2048 --height 2048 --diffusion-steps 40 --cfg 1 \
  --diffusion-seed 42 --output generated.png

# 图像编辑
dotnet run --project TensorSharp.Cli -c Release --no-build -- \
  --config config/qwen-image-2.1.json \
  --image generated.png \
  --prompt 'Change the blue vase to a red vase. Preserve the cat, lighting and composition.' \
  --width 2048 --height 2048 --diffusion-steps 40 --cfg 1 \
  --diffusion-seed 42 --output edited.png

# 服务端 + Web UI
dotnet run --project TensorSharp.Server.Host -c Release --no-build -- \
  --config config/qwen-image-2.1.json --host 127.0.0.1 --port 5000

如需自己下载这四个文件，请显式传入伴随文件：

hf download Abiray/Qwen-Image-2.1-GGUF qwen_image_2.1_Q4_K_M.gguf --local-dir models
hf download Comfy-Org/Qwen-Image-2.1 vae/qwen_image_2.1_vae_bf16.safetensors --local-dir models
hf download Qwen/Qwen3-VL-8B-Instruct-GGUF Qwen3VL-8B-Instruct-Q4_K_M.gguf mmproj-Qwen3VL-8B-Instruct-F16.gguf --local-dir models

dotnet TensorSharp.Server.Host/bin/TensorSharp.Server.Host.dll --model models/qwen_image_2.1_Q4_K_M.gguf \
    --qwen-image-vae models/vae/qwen_image_2.1_vae_bf16.safetensors \
    --qwen-image-vl models/Qwen3VL-8B-Instruct-Q4_K_M.gguf \
    --qwen-image-mmproj models/mmproj-Qwen3VL-8B-Instruct-F16.gguf \
    --backend ggml_cuda

下载大小并不等于推理峰值内存：运行时内存还包括激活值、解码缓冲区和工作权重，更大的图像和多张参考图都会提高内存需求。

图像生成与编辑（Qwen-Image-2.1）

所加载的 qwen_image GGUF 是 Qwen-Image-2.1 扩散 Transformer。TensorSharp 在其旁解析伴随文件——专用 2.1 VAE、Qwen3-VL-8B 文本编码器，以及编辑时使用的 Qwen3-VL mmproj 视觉编码器——也可以用 --qwen-image-vae / --qwen-image-vl / --qwen-image-mmproj 指定（环境变量：TS_QWEN_IMAGE_VAE / TS_QWEN_IMAGE_TE / TS_QWEN_IMAGE_MMPROJ）。原生 RGBA 输入与 PNG 输出保留透明度：Qwen3-VL 条件分支把参考图合成到白色背景上，而 VAE 保留 alpha 通道。

  • 生成还是编辑。不带 --image 时执行生成；带一个或多个 --image 时执行编辑，参考图按给出的顺序使用。也可以用 --input prompt.txt 代替 --prompt 提供提示词。
  • 采样默认值。省略设置时使用 40 步 Euler 和 CFG 1.0，遵循 Qwen 推荐的无引导采样——每步只做一次 Transformer 预测。显式设置大于 1 的 CFG 会增加负向预测并应用 --negative-prompt；在 CFG 1 下负向提示词不起作用。
  • 尺寸。省略尺寸时，生成为 2048×2048；编辑则取与第一张参考图宽高比一致、像素面积大致相同的尺寸。要覆盖此行为，请同时设置宽度和高度，且都取 32 的倍数。每张参考图以约 1 百万像素（若输出面积更小，则以输出面积）作为条件输入。
  • 调度。遵循官方调度器配置：指数动态偏移（序列长度/偏移锚点为 256/0.5 与 8192/0.9），随后终端拉伸到 0.02，并以最后一个 Euler 步走到零。
  • 执行。扩散 Transformer 以常驻量化权重运行一张完整的 GGML 图，因此需要 GGML 后端（ggml_metal、ggml_cuda、ggml_vulkan 或 ggml_cpu）。CUDA 与 Metal 会在多次预测之间保留这张图（TS_QWEN21_GRAPH_REUSE=1，默认开启）。没有 CPU 权重流式加载模式，也不支持 LoRA；内存不足时请先用较小的尺寸。

提速的关键是分辨率和步数。2K 正方形的潜在图像 token 数是 1K 正方形的四倍，注意力计算也更多，因此 --width 1024 --height 1024 是草图设置。--diffusion-steps 25 --cfg 1 是官方 ComfyUI 生成与编辑工作流使用的更快配置；默认仍为 40 步，更少的步数是质量与速度之间的权衡，并不代表质量相当。CFG 1 本身就意味着每步只做一次 Transformer 前向。快速冒烟测试可用 256×256、一步，它只验证加载和端到端数据通路，不说明图像质量。

可从 CLI（--prompt，编辑时再加 --image）、Web UI（不带附件的提示词会生成图像；附加一张或多张图像即可编辑，并有实时去噪预览）、HTTP API（/api/image-generate 与 /api/image-edit，各有 /stream 变体），或在进程内从 C# 通过 QwenImageModel.GenerateImage() / EditImage() 运行。由于扩散流水线共享可变的工作状态，图像操作会串行执行。完整细节见仓库的 Qwen-Image-2.1 卡片（验证记录见英文版）。
